First of all, I want to point out that **Linux** is not an operating system but a kernel. What the general public calls the **Linux** operating system is actually **GNU/Linux**. In this article as well, to address the target audience, I will use **Linux** instead of **GNU/Linux**.

Now that I have sparked a bit of curiosity in you, let's start with the history of the **Linux** operating system.


In 1969, Ken Thompson and Dennis Ritchie created the UNIX operating system. This operating system was very much liked by companies and universities. Everything was going well for UNIX, but the code of the operating system belonged to the AT&T company. This slowed down the developers' work of improving the UNIX operating system. Without AT&T's approval, they could not make any changes to the code.


In 1984, Richard Stallman started the GNU project, wanting to create a free UNIX-like operating system. By 1991, many of the programs in the UNIX operating system had been made open source within the GNU project, but these programs needed a kernel in order to interact with the hardware. ([**GNU project page**](https://www.gnu.org/gnu/gnu.html))

<img src="https://cdn-images-1.medium.com/max/1024/1*eAjNrVieWpXZCjzrKrrqpg.png" alt="Image" />
*A simple diagram of the Linux kernel.*


Well, what a coincidence ^^. In 1991, Linus Torvalds, who was studying Computer Science at the University of Helsinki, was writing a kernel. This kernel would later be named **Linux**. Linus wrote this kernel specifically for the hardware he used and to be independent of any operating system. ([Wikipedia](https://en.wikipedia.org/wiki/Linux))

<img src="https://cdn-images-1.medium.com/max/504/1*hcpbuNRgSeIQ39Gna-ywTQ.png" alt="Image" />
*Linus Torvalds' first post announcing the Linux kernel.*


In 1992, he released this kernel as an open-source project under the GPL license. Then, with **Linux** being combined with the GNU project, the **GNU/Linux** operating system was born. Since this project is open source, it gave people the opportunity to develop and customize the operating system however they wanted.


Here we can see very clearly what potential an open-source project can have. In his mail, Linus wrote that he was developing the **Linux** kernel as a hobby. Of course, at that time he did not predict that the kernel he had made would grow this much and become the operating system that **80.2% of all the world's servers** would use. :) (see: [Source](https://w3techs.com/technologies/history_overview/operating_system))


Now that we have learned its history, we can move on to our actual topic: **“Why should we use Linux”**.

### 1-**Linux** is more secure.

<img src="https://cdn-images-1.medium.com/max/1024/1*XwprTEu_Oc_qVNIrqWbwKw.png" alt="Image" />
*[https://www.t4.ai/industry/desktop-operating-system-market-share](https://www.t4.ai/industry/desktop-operating-system-market-share)*


As you can see in the graph, the Windows operating system holds a significant place in the end-user market. The people who write viruses are of course aware of this rate. In addition, since the average Windows user is not “in the business” like us, they are not very careful about security. That's why the vast majority of the viruses written target Windows.


As we mentioned above, **GNU/Linux** is an open-source operating system. You might be thinking; “Since it is open source, why doesn't any hacker examine the code and exploit this vulnerability?” Because this operating system is used in the world more by companies and the like than by end users, the code is first examined by millions of well-intentioned hackers and reported instantly; and again thanks to it being open source, it is reported to volunteer developers so that it can be fixed.


Now let's look at this matter from Windows' point of view as well. In an operating system like Windows, whose source code is closed, no one other than Windows' own “well-intentioned hackers” can examine this code. When someone finds a vulnerability, rather than reporting it (like a Zero Day), they can earn more money by selling it or exploit it however they want. A vulnerability can only be closed when it is noticed. And until then, whoever exploits it has already exploited it anyway.


On the **Linux** operating system, although it is not recommended, you can download programs from your browser just like on Windows; however, using a package manager, you can also download this package directly from its source. This way, you both save time and prevent a virus from infecting your computer.


On **Linux**, a program started with normal privileges cannot make any modification on the system. To be able to do that, it needs to log in with “root” privileges by entering a password. Since most users do not log in with “root” privileges, even if a virus infects your **Linux**-installed computer, the things this virus can do will be limited.

### 2-High Stability

We mentioned that the **Linux** operating system is used on servers at a rate of 80.2%. For this reason, this fact is also taken into account while **Linux** is being developed. In order for servers to remain accessible, it needs to run smoothly 24/7 and not crash or give a blue screen while updating.


Comparing it with Windows: you must have noticed how fast a freshly installed Windows is, but as time goes by, six months to a year later, this speed drops compared to the first installation. **Linux**, on the other hand, whether one year or decades have passed since its installation, can run at the same speed again.


When an update arrives on a **Linux** server or it has been on for a long time, it can keep working without needing to be shut down or restarted. This is not the case for Windows.

### 3-The **Linux** operating system is much easier to maintain and manage.

On **Linux**, every distro has its own package manager. Since you perform the downloading of programs or the updating process from here, you don't need to update each program from separate locations. You can easily do all of them from a single location.

### 4-**Linux** can run on a wider range of hardware levels compared to Windows.

On Windows, you may hate downloading drivers. **Linux** supports many devices without requiring an extra installation.


When you want to update to Windows 11, if your computer is old, it may not accept it or may run slowly; even if it is new, you can still have trouble with the update. Windows has a certain minimum operating system range. Since **Linux** has a “distro” suited to every level range, you can run the latest released Linux kernel even on your decade-old computer. This way, you don't miss out on security updates.


Note: On some laptops, e.g. fan modes or keyboard lighting modes, problems can occur because the manufacturer does not provide software support for **Linux**. Personally, I experienced this, but people who had the same problem as me wrote a program to fix it (see:[https://asus-linux.org/](https://asus-linux.org/)) .Of course, this could be solved thanks to Linux being open source :)

Finally, there are some prejudices I see against **Linux**. I would like to break those down as well.

### 1-You can't play games on **Linux**!!

This used to be true, but nowadays, ever since Steam entered the market with its own console named “Steam Deck”, I can say firsthand, as a full-time **Linux** user myself, that things are progressing positively. Of course, games with special anti-cheat protection (like League of Legends, Valorant, RS6) unfortunately cannot be played at the moment. Everything may change in the future, of course :)


Also, by using Lutris and Wine, you can emulate a Windows application to run on **Linux**.

### 2-**Linux** is very hard! It is made only for people who are knowledgeable about computers (NERDs).

<img src="https://cdn-images-1.medium.com/max/544/1*2H5mlbdnNAviqSdV5kFKrw.jpeg" alt="Image" />

Since you have never used your computer with anything other than Windows, of course you will go through an adaptation process at first. You can easily get over this adaptation process as follows.


Create a **Linux** virtual machine inside your computer and start experiencing it little by little. Use this virtual machine even for browsing the internet. Then, research the alternatives to the programs you are accustomed to and start using them. This way, your transition from Windows to **Linux** will become easier.


Besides, I can say that as long as you don't go and start using **Linux** with a window manager (see: dwm, i3), you can get used to it with ease.
