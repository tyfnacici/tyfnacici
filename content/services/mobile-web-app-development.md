## Overview
I build production-grade mobile and web applications that scale. From cross-platform mobile apps in Flutter and React Native to full-stack web platforms in TypeScript and Node.js I deliver clean maintainable code with a focus on user experience and performance.

## What I Offer
### Mobile Applications
- Cross-platform apps with Flutter (Dart) or React Native (TypeScript) single codebase native performance on iOS and Android
- Native integrations: Camera GPS notifications biometrics speech recognition and offline storage
- App lifecycle: From App Store / Play Store submission to ongoing maintenance and updates

### Web Applications
- SPA and SSR: React/Next.js for dynamic single-page apps Hugo for blazing-fast static sites
- RESTful and GraphQL APIs: TypeScript backends with Express Fastify or NestJS
- Real-time features: WebSocket-based live updates collaborative editing push notifications
- Responsive design: Mobile-first works on every screen size

### My Approach
1. Discovery: Requirements gathering wireframing tech stack selection
2. Development: Agile sprints with continuous integration and testing
3. Delivery: CI/CD pipeline setup cloud deployment monitoring
